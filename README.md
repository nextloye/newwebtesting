# Zyntrix Hosting Platform

Complete hosting platform for Pterodactyl Panel.

## Features
- Minecraft server hosting
- VPS hosting
- Web hosting
- Live statistics with WebSocket
- Admin panel
- Responsive design

## Installation on Pterodactyl
1. Create new Node.js server
2. Set port to 25569
3. Use this repository
4. Set main file to `server.js`
5. Add packages: `express socket.io dotenv`

## Access URLs
- Main: http://your-ip:25569
- Minecraft: http://your-ip:25569/minecraft
- Admin: http://your-ip:25569/admin?password=admin123
